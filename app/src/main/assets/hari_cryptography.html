HARI BROWSER

Cryptography Tools

Local encryption for text and files, including exported bookmark/history backups.

Privacy by design: processing happens in this page; it does not upload data. Use a strong, unique password and keep a backup. Losing the password means the data may be unrecoverable.
This tool does not encrypt all browser traffic or automatically protect HARI Browser's live databases. It requires Web Crypto support in a secure context.

Text encryption

Encrypt private notes, snippets, or text. Output is a versioned HARI encrypted container.

Files and encrypted backups

Use this for documents or exported bookmark/history backup files. Export the data from the browser first; this page cannot access live browser databases by itself.

Maximum supported file size: 8 MiB. Larger files need a reviewed streaming-encryption implementation.
Format: versioned JSON envelope containing algorithm, PBKDF2 iteration count, random salt, random AES-GCM IV, original filename metadata, and authenticated ciphertext. Metadata is authenticated during encryption/decryption.
Security note: this page uses the browser's Web Crypto API (PBKDF2-HMAC-SHA-256 and AES-256-GCM). This is a practical utility, not a security certification. Avoid using it on a shared or compromised device.
